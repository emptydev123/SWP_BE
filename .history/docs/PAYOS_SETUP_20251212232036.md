# Hướng dẫn Setup PayOS Payment Integration

## Tổng quan

Hệ thống đã được tích hợp PayOS để xử lý thanh toán cho:
1. **Phí gia nhập CLB**: Khi sinh viên được duyệt tham gia CLB và cần đóng phí
2. **Mua vé event**: Khi sinh viên muốn mua vé cho các event có tính phí

## Cấu hình Environment Variables

Thêm các biến sau vào file `.env`:

```env
# PayOS Configuration
# Lấy từ PayOS Dashboard: https://pay.payos.vn/web4/
PAYOS_CLIENT_ID="your-payos-client-id"
PAYOS_API_KEY="your-payos-api-key"
PAYOS_CHECKSUM_KEY="your-payos-checksum-key"

# PayOS URLs (Optional - có thể để mặc định)
PAYOS_BASE_URL="https://api.payos.vn/v2"
PAYOS_RETURN_URL="http://localhost:3000/api/transactions/return"
PAYOS_CANCEL_URL="http://localhost:3000/api/transactions/cancel"
```

## Cách lấy thông tin từ PayOS

1. Đăng ký tài khoản tại: https://pay.payos.vn/
2. Đăng nhập vào Dashboard: https://pay.payos.vn/web4/
3. Vào mục **API Integration** để lấy:
   - `PAYOS_CLIENT_ID`: Client ID của bạn
   - `PAYOS_API_KEY`: API Key để authenticate requests
   - `PAYOS_CHECKSUM_KEY`: Key để verify webhook signature

## Cấu hình Webhook

1. Trong PayOS Dashboard, vào **Webhook Settings**
2. Set Webhook URL: `https://your-domain.com/api/transactions/webhook`
3. PayOS sẽ gửi POST request đến endpoint này khi có thay đổi trạng thái payment
4. Hệ thống sẽ tự động verify signature và cập nhật transaction status

## API Endpoints

### 1. Tạo payment link chung (hỗ trợ cả MEMBERSHIP và EVENT_TICKET)

**POST** `/api/transactions/create-payment`

**Headers:**
```
Authorization: Bearer <token>
```

**Body cho MEMBERSHIP:**
```json
{
  "type": "MEMBERSHIP",
  "membershipId": "uuid-of-membership"
}
```

**Body cho EVENT_TICKET:**
```json
{
  "type": "EVENT_TICKET",
  "eventId": "uuid-of-event",
  "ticketType": "STANDARD",
  "quantity": 1
}
```

**Response (MEMBERSHIP):**
```json
{
  "success": true,
  "message": "Tạo payment link thành công",
  "data": {
    "transactionId": "uuid",
    "paymentLink": "https://pay.payos.vn/web/...",
    "orderCode": 1234567890,
    "amount": 50000,
    "description": "Phí gia nhập CLB: FPT Software Engineering Club"
  }
}
```

**Response (EVENT_TICKET):**
```json
{
  "success": true,
  "message": "Tạo payment link thành công",
  "data": {
    "transactionId": "uuid",
    "paymentLink": "https://pay.payos.vn/web/...",
    "orderCode": 1234567890,
    "amount": 100000,
    "quantity": 1,
    "tickets": [
      {
        "id": "ticket-uuid",
        "ticketType": "STANDARD"
      }
    ],
    "description": "Mua vé event: Event Name"
  }
}
```

### 2. Webhook endpoint (tự động xử lý)

**POST** `/api/transactions/webhook`

PayOS sẽ tự động gọi endpoint này khi có thay đổi trạng thái payment.

### 4. Return URL (sau khi thanh toán thành công)

**GET** `/api/transactions/return?orderCode=1234567890&status=PAID`

### 5. Cancel URL (khi user hủy thanh toán)

**GET** `/api/transactions/cancel?orderCode=1234567890`

### 6. Lấy thông tin transaction

**GET** `/api/transactions/:transactionId`

**Headers:**
```
Authorization: Bearer <token>
```

## Flow thanh toán

### Flow 1: Phí gia nhập CLB

1. Sinh viên đăng ký tham gia CLB → Tạo `ClubApplication`
2. Admin duyệt application → Tạo `ClubMembership` với status `PENDING_PAYMENT`
3. Sinh viên gọi API `/api/transactions/membership-payment` → Nhận payment link
4. Sinh viên thanh toán trên PayOS
5. PayOS gửi webhook → Hệ thống cập nhật:
   - `Transaction.status` = `SUCCESS`
   - `ClubMembership.status` = `ACTIVE`
   - Tạo `ClubLedger` entry cho CLB

### Flow 2: Mua vé event

1. Sinh viên chọn event có tính phí
2. Gọi API `/api/transactions/event-ticket-payment` → Nhận payment link
3. Hệ thống tạo:
   - `Transaction` với type `EVENT_TICKET`
   - `Ticket`(s) với status `RESERVED`
4. Sinh viên thanh toán trên PayOS
5. PayOS gửi webhook → Hệ thống cập nhật:
   - `Transaction.status` = `SUCCESS`
   - `Ticket.status` = `PAID`
   - Tạo `ClubLedger` entry cho CLB

## Xử lý lỗi

- Nếu thanh toán thất bại hoặc bị hủy:
  - `Transaction.status` = `FAILED` hoặc `CANCELLED`
  - `Ticket.status` = `CANCELLED` (nếu là event ticket)
  - `ClubMembership.status` vẫn giữ nguyên `PENDING_PAYMENT`

## Testing

1. Sử dụng PayOS Sandbox environment để test
2. Có thể test webhook bằng cách gửi POST request đến `/api/transactions/webhook` với payload mẫu từ PayOS docs

## Lưu ý

- `orderCode` phải là số nguyên dương, unique
- Hệ thống tự động generate orderCode từ timestamp + random
- Payment link sẽ expire sau 1 giờ (có thể config trong `payosService.js`)
- Webhook signature được verify tự động để đảm bảo security
